# IronForge Gym

## View the website

Clicking the HTML file on GitHub shows its source code; it does not publish the site. To publish it with GitHub Pages:

1. Open the repository's **Settings > Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and the `/(root)` folder, then save.
4. After the Pages deployment finishes, open <https://swapnil2283.github.io/Gym-website/>.

The root `index.html` forwards visitors to the main site file. Commit and push website changes to `main` before expecting them to appear on GitHub Pages.
